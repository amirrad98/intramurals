# LeagueFlow 1.0.2

- Adds WordPress update discovery and plugin details from public GitHub releases.
- Verifies each release ZIP against its version-specific SHA-256 before installation.
- Adds tested, deterministic WordPress ZIP builds and GitHub Actions publication.
- Preserves the live-site 1.0.1 gameplay, roster, calendar and privacy behavior.

Requires WordPress 6.5 or later and PHP 8.1 or later. Install the attached
`leagueflow-1.0.2.zip` once through Plugins → Add New → Upload Plugin, replacing
the existing LeagueFlow installation. Keep the plugin active to discover future
releases through WordPress's normal update checks. Administrators choose when to
update; this release does not enable automatic updates for them.

The `leagueflow/` directory remains stable and an update replaces plugin files,
without uninstalling the plugin or replacing website content. GitHub's generated
source archives are development downloads; the attached versioned plugin ZIP is
the installable distribution.

Validation covers PHP 8.1–8.4, deterministic packaging, updater failure cases and
native update/install behavior on disposable WordPress 6.5 and current stable
sites. It does not certify every theme, host or existing site's league workflows.
