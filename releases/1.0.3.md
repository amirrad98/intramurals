# LeagueFlow 1.0.3

- Prevents player editors from linking privileged users, changing account roles or resetting existing passwords. Authorized administrators provision new accounts with a WordPress password-setup email; passwords are never shown in plugin notices.
- Enforces team visibility and password protection across profiles, lists and rosters.
- Restricts global field configuration, scheduling and fixture generation with dedicated capabilities, and validates each target before scheduling or bracket advancement.
- Enforces calendar event publication and taxonomy permissions on both REST creation endpoints.
- Paginates public match/calendar queries in the database: default 20, maximum 100 items per page. Match archives include page navigation.
- Adds real WordPress security regression checks to the release pipeline on WordPress 6.5 and current stable, alongside existing package and update checks.

Requires WordPress 6.5+ and PHP 8.1+. The new management capabilities are granted to administrators automatically on upgrade. Custom roles must receive the relevant capability explicitly, alongside WordPress's normal post/user permissions. Field availability permission applies globally.

Use the attached `leagueflow-1.0.3.zip` when this release is published. Active updater-enabled installations discover it through normal WordPress plugin updates. Existing accounts keep their passwords; league data and the `leagueflow/` directory are preserved.
