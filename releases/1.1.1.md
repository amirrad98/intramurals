# LeagueFlow 1.1.1

## Results and progression

- Automatically finish Scheduled matches when both valid scores or a forfeit are
  saved. Preserve zero scores, missing-score distinctions, deliberate non-final
  statuses and a persistent keep-status option for reopening/provisional entry.
- Save protected result fields together, reject stale forms and emit lifecycle
  events after verified commit. Preserve sport-specific multiline match notes.
- Synchronize linked knockout fixtures after final results, score corrections,
  reopening and trash/restore. Preserve started or incompatible targets and show
  an actionable review notice. Scope referee progression to the committed result.
- Align public match cards/lists, calendars, brackets and result feeds for forfeits,
  explicit knockout winners, malformed legacy scores and incomplete fixtures.

## Admin and sport configuration

- Preserve sport, level, competition, season, generated batch and lifecycle context
  through list views and navigation; keep publication and match status distinct.
- Clarify menus, breadcrumbs, dashboard counts, selectors and responsive forms.
- Preserve customized sport labels, reject empty/invalid sport setup and validate
  competition/season ownership across classic forms and supported REST paths.
- Inherit points, tie-breakers and forfeit scores independently from global to sport
  to competition rules. Blank inherits; zero remains an explicit override.
- Reject unsupported generic REST match result/context writes before partial saves.

## Scheduling and verification

- Verify date, venue, duration, provenance and generated title as one schedule
  update, roll back failed writes, and reserve slots only after success.
- Reject malformed scheduling identifiers and refuse scheduling inside unfinished
  caller transactions without committing or rolling back their work.
- Extend native WordPress, JavaScript, permissions, rollback and regression checks.
- See `docs/SCORING-ADMIN-REVIEW-2026-10-21.md` for tested behavior and limitations.

Existing league records are not bulk-finalized or reclassified by installing this
update. Review existing scored Scheduled fixtures before finalizing them. Branch
builds and pull requests are review artifacts; stable publication and site
installation remain separate actions.
